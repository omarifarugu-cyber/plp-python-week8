
# Week 8 Final Project: Personal Mini-Toolkit

## Project Description

My Personal Mini-Toolkit is a Python program that provides three useful tools through a menu-driven system.

## Tools Included

### 1. Simple Calculator
Performs addition, subtraction, multiplication and division.

### 2. To-Do List
Allows users to add, view and remove tasks.

### 3. Number Guessing Game
Allows users to guess a secret number between 1 and 10.

## Python Concepts Used

- Variables
- User input and output
- If, elif and else statements
- While loops and for loops
- Lists
- Functions
- F-strings
- Exception handling

## How to Run the Program

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run this command:

```bash
python toolkit.py
```

## Project Reflection

The hardest part of this project was creating the menu system and connecting all three tools. I learned how to use loops to keep the program running until the user chooses to quit. The most challenging part was handling invalid user inputs without crashing the program. I also learned how lists can store and manage tasks. Testing the different tools helped me understand Python conditionals better. If I had one more week, I would add a feature that saves tasks permanently in a file.
